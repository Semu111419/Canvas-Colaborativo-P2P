Instrucciones de Uso

📱 Procedimiento de Conexión (2 Celulares)

  • Celular 1 (Anfitrión): Pulsa "Conectar" → pestaña Anfitrión → pulsa "Crear sala". Mostrará un QR.
  • Celular 2 (Invitado): Pulsa "Conectar" → pestaña Invitado → pulsa "Escanear QR" y enfoca la pantalla del Celular 1.
  • Completar enlace: El Celular 2 mostrará su propio QR de respuesta. El Celular 1 pulsa "Escanear Respuesta" y enfoca la pantalla del Celular 2.
  • ¡Listo! Ambos quedan conectados directamente mediante WebRTC DataChannel sin servidores intermedios.

🎨 Gestos del Canvas Infinito

  • Desplazamiento (Pan): Desliza un dedo sobre el fondo vacío para mover el lienzo.
  • Zoom: Usa dos dedos (pellizco) para acercar o alejar, o usa los botones laterales (+ / -).
  • Manipular imagen: Toca una imagen para seleccionarla. Arrastra desde las esquinas para escalar o rotar, y desde el cuerpo para mover.
  • Cámara Compartida: El usuario que mueva el lienzo tomará el control visual reflejando la vista en el otro celular en tiempo real.

🔒 Privacidad y P2P

Tus imágenes y dibujos viajan directamente entre ambos celulares a través de un canal de datos WebRTC cifrado. No se almacenan en ningún servidor ni base de datos.
